# ⚽ DRIBBLE RUNNER 8-BIT（サッカードット絵エンドレスランナー）

白黒縦縞ユニフォーム（FUJITSUロゴ風）を着たエースストライカーを操作し、次々と立ちはだかるディフェンダーを神技ドリブルとジャンプでかわし続けるスーパーマリオ風レトロWebゲームです。

---

## 🎮 遊び方

### 操作方法
| 操作 | アクション |
| :--- | :--- |
| **画面タップ**（スマホ） / **マウスクリック** / **スペースキー** / **↑キー** | **ジャンプ** |
| **長押し** | **大ジャンプ**（巨漢DFを跳び越えるときに有効！） |
| **短くタップ** | **小ジャンプ**（素早く着地して次の障害物に備える） |

### ルール
- プレイヤーは常に自動で右方向へドリブル前進します。
- 迫り来る障害物をジャンプでかわしてください：
  - **スライディングDF**: 低姿勢で地面を滑り込んできます。早めのジャンプで飛び越えましょう。
  - **タックルDF**: 前傾姿勢で突進してくる標準サイズのDF。
  - **巨漢DF（壁）**: 背が高く体格が大きいDF。長押しの大ジャンプで頭上ギリギリを抜きましょう！
  - **荒れた芝（泥トラップ）**: 芝生がめくれ上がったトラップ。足を取られると転倒します。
- **接触したら即座に審判のホイッスル（ピピーッ！）でファウル判定＆スタートに戻ります**。
- かわしたDFの人数（BEATEN）とドリブル距離（m）のハイスコアを競います！

## 🚀 起動方法

### 方法1: ブラウザで直接開く（最速）
Finderまたはターミナルから `index.html` をダブルクリック、もしくは以下のコマンドで開くだけで即プレイ可能です。
```bash
open /Users/ken/.gemini/antigravity/scratch/pixel-soccer-runner/index.html
```

### 方法2: ローカルWebサーバーで起動
```bash
cd /Users/ken/.gemini/antigravity/scratch/pixel-soccer-runner
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスしてください。

## ✨ こだわりポイント
1. **キャラクターのドット絵再現**:
   - 褐色の肌、短髪パーマ、ヒゲ、白黒ストライプ（FUJITSUロゴ・エンブレム）をレトロなピクセルアートで忠実に再現。
   - 走る足の運び・ドリブルのボール回転・跳躍時の抱え込みポーズ・倒れた時のクラッシュポーズを用意。
2. **ボールの神技ドリブル挙動**:
   - 地面走行時は足元でチョンチョンとバウンド＆回転し、ジャンプ時は足元に吸い付くように一緒に舞い上がります。
3. **8bitレトロサウンド（Web Audio API）**:
   - 外部音声ファイル不要。ブラウザ単体で軽快なサンバ調BGM、ジャンプ音、ドリブルキック音、かわした時のピコーン音、審判のホイッスル「ピピーッ！」音を合成再生します。
4. **スタジアムの演出**:
   - ピッチの芝生刈り込み模様、観客席のピコピコ応援ドット、カクテル照明塔、距離が進むにつれて昼景から夕焼け、ナイターへ変化する空のパララックス（多重スクロール）背景。
